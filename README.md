# Bimbi

A minimal desktop widget for storing and revisiting quotes that matter to you.

Built with Electron. Sits quietly on your desktop — transparent and out of the way until you need it.

## Features

- Add and store quotes with author names
- Star quotes to bookmark them for quick access
- Search by quote text or author
- Transparent desktop widget — hovers below all apps, reveals on mouse hover
- Auto-hides after 5 minutes of inactivity

## Install & Run

```bash
npm install
npm start
```
